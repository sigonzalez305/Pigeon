# Pigeon graphics inventory

The ZIP contains 22 original design PNGs, 4 byte-identical GitHub sprite strips, one resized pet/happy strip, one legacy SVG, and 26 exports of existing Figma graphics.

All five packaged runtime strips contain eight distinct, nonempty 256×256 cells on a transparent background and measure 2048×256. The pet/happy export uses 4× nearest-neighbor scaling from the 512×64 source. The source has eight 64×64 frames.

The original design PNGs and valid GitHub assets retain their filenames and bytes. The Figma export names were assigned for this ZIP. The Figma links point to the original editable nodes. Their raster exports are at 1× and SVG dimensions are the exported viewport.
